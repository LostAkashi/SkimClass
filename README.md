
# SkimClass - 基于大模型智能体的助教系统

SkimClass 是一款专为大学课堂与在线课程设计的“上课能用、课后好复习”的智能助教系统。它能够通过多模态感知技术自动采集课堂信息，结合大语言模型（LLM）与检索增强生成（RAG），为学生提供实时知识总结、精准答疑、个性化测验及学习报告，打造全方位的“伴学体验”。

## 用户下载项目后如何启动

1. 第一步：安装依赖

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. 第二步：运行应用

```bash
streamlit run app.py
```

3. 第三步：在页面中填写 `API Key`，开始使用。

4. 第四步（macOS 首次录制时）：在系统中允许麦克风和屏幕录制权限。



## 🌟 核心功能特性

- **多模态智能采集**：在不打扰听课的前提下，后台自动进行屏幕关键帧提取（PPT翻页、板书更新等明显变化作为触发条件）与音频实时转写，实现真正的无感记录。
- **全面的数字上下文与精准答疑 (RAG)**：构建了多层上下文约束机制。回答问题时，系统会优先基于本节课的真实记录（第一层）与权威指定的课程资料（第二层）进行生成，确保每一句回答都“有据可查”，大幅降低大模型的“幻觉”现象。
- **分段总结与自动生成大纲**：以15分钟为单位滚动生成“要点清单+术语表+待解问题”，并在课后自动汇总为结构化的课程大纲，突出主线与易错点。
- **边学边测与个性化复习**：结合课堂进度自动生成随堂小测（单选/判断为主），并根据错题记录建立“专属错题本”，追踪知识掌握度并自动规划复习路线。
- **边缘计算与隐私保护**：优先在本地设备（如笔记本、平板）进行语音和图像的初步处理，仅将结构化文本发送至云端大模型，默认不长期存储原始音视频，保障课堂合规与数据安全。

## 📁 项目结构

- `app.py` / `pages/` - 应用程序主入口及各类前端页面视图。
- `auto_capture.py` - 负责屏幕截图与音频的多模态信息自动采集与录制控制。
- `agent.py` - 核心智能体逻辑，对接大语言模型（如 DeepSeek、豆包 API）处理分段总结与答疑。
- `db.py` - 本地数据与状态管理，负责结构化处理后数据的存储调度。
- `data/recordings/` - 本地存放原始音视频与截图流的缓存目录（按隐私策略设计，可随时一键清除）。
- `launcher.py` / `paths.py` - 系统启动流程控制与核心路径配置。
